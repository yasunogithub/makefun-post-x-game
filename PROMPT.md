# The one prompt this game was built from

"Make a tiny browser game: you are the make.fun ghost, you collect magenta
star coins, red bugs cost you points, 60 seconds on the clock, arrow keys."

The finished game is `game.html` (one file, no dependencies — open it in any
browser). The bounty entry itself is a short X video showing this prompt,
the agent building the game, and the game running; see POST-TEXT.md.
